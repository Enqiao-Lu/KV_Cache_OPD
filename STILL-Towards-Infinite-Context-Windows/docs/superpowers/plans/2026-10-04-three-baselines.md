# Three QASPER Baselines Implementation Plan

> Implement inline with test-driven-development and verification-before-completion.

**Goal:** Compare frozen Qwen3-4B full KV, STILL-style forward-KL distillation,
and full-context student-on-policy JSD using the existing question-independent
compactor. Exclude evidence-teacher training from the first comparison.

**Architecture:** Extend `still.train.opd` with full-cache evaluation and fixed
full-teacher answer trajectories. Extend the existing runner with explicit method
selection; keep its full/evidence CLI backward compatible. Reuse existing QASPER
F1, cache, chat, gradient, checkpoint and sampling interfaces.

**Constraints:** Freeze the exact backbone revision; train only the compactor.
Match initialization, document schedule, learning rate, slots, generation limits
and evaluation questions. Compress once per document without the question. Use
gold answers only for evaluation. Do not publish formal effectiveness claims from
a short smoke. The STILL baseline is a QASPER adaptation of the forward-KL
objective: fixed answers generated by the full teacher and full-vocabulary KL,
rather than the paper's MCQ targets and top-200 approximation.
